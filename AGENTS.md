- Использовать функциональный подход: небольшие функции с одной задачей, без классов для логики приложения.
- Давать переменным и функциям понятные названия. Комментариями на русском объяснять назначение и неочевидную логику.

- Внутренние страницы используют отдельный компактный хедер: логотип слева, меню справа.

## Форматирование HTML и структура страницы

- Каждый открывающий и закрывающий HTML-тег писать с новой строки. Не объединять несколько тегов в одну строку.
- Использовать отступы в 2 пробела на каждый уровень вложенности. Текст внутри элементов также размещать на отдельной строке.
- Не минифицировать исходные HTML-файлы. Форматирование должно сохраняться при последующих изменениях.
- Общая структура: обертка страницы, затем header, main с section, затем footer. Хедер всегда расположен перед main и секциями в исходном HTML.
- На главной хедер визуально накладывается на обложку через CSS; ради этого нельзя переносить его внутрь section или после слайдов.
- После форматирования проверять сохранность атрибутов, ссылок и значимого текста, а после изменения структуры — расположение хедера на десктопе и мобильном.

## Форматирование и вложенность CSS

- Использовать обычный `.css` с нативной CSS-вложенностью, без SCSS и препроцессора.
- Каждое свойство писать на отдельной строке: пробел после двоеточия, точка с запятой в конце.
- Отступы — 2 пробела. Открывающая фигурная скобка на строке селектора, закрывающая — на отдельной строке. Между правилами оставлять пустую строку.
- Связанные дочерние селекторы и состояния группировать внутри соответствующего правила: `& img`, `&:hover`, `&.is-open`, `&::after`.
- Не использовать SCSS-конкатенацию `&__element` и `&--modifier`: нативный CSS ее не поддерживает. БЭМ-классы писать полностью.
- Не добавлять лишний родительский класс ради вложенности: сохранять специфичность селекторов и порядок каскада.
- При рефакторинге сравнивать вычисленные стили и адаптивную верстку до и после изменений.
