# 1001 DAY

Сайт интерьерной студии: проекты, услуги, информация о студии, публикации и контакты.

## Локальный запуск

```sh
python3 -m http.server 8011
```

Откройте http://localhost:8011.

## Структура

- HTML-файлы — страницы сайта.
- `styles.css` — стили и адаптивная верстка.
- `script.js` — слайдеры, меню, диалог консультации и аккордеоны.
- `assets/` — изображения, иконки, шрифты и локальная библиотека Swiper.

## Размещение

Статический сайт без сборки. Корень публикации — папка проекта, стартовая страница — `index.html`.

Форма консультации требует подключения серверного API. До подключения отправка недоступна.
