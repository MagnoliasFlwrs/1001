## Запуск

Из папки проекта:

```sh
python3 -m http.server 8011
```

Открыть http://localhost:8011.

- `index.html` — главная.
- `projects.html` — выбор категории. Обе категории ведут в `commercial-projects.html`.
- `commercial-projects.html` — список из четырех проектов.
- `project.html` — галерея из 11 изображений; сюда ведут все карточки, включая главную.
- `styles.css` — стили по БЭМ и адаптивная верстка.
- `script.js` — Swiper, меню и модальная форма; функции и русские комментарии.
- `assets/` — локальные изображения, иконки, шрифты и Swiper 12.
- `AGENTS.md` — правила дальнейшей разработки.

Контент ограничен 1820px, горизонтальные паддинги 16px. Меню выезжает справа. Форма выезжает сверху и останавливается по центру экрана. Высота определяется содержимым и ограничена высотой экрана, с внутренней прокруткой. На мобильной версии проекты идут последовательно.

Страницы «О нас», «Услуги», «Контакты» и «Публикации» реализованы и подключены в меню и футерах. Форма не отправляет данные на сервер.

Проверено в браузере на ширинах 1920 и 393px: загрузка изображений, отсутствие горизонтального скролла, переключение слайдов, открытие и закрытие меню, Escape, высота модального окна. JS проверен `node --check script.js`.

Внутренние страницы используют отдельный компактный хедер с логотипом слева. Каталог и галерея: три колонки на десктопе, две на планшете, одна на телефоне. Начальная надпись о демонстрационной форме удалена. Проверены ширины 1920, 1024 и 393px, переходы по категориям и карточкам, внутреннее меню и отсутствие горизонтального скролла.

Добавлены `services.html` («Услуги»), `about.html` («О нас») и `contacts.html` («Контакты»). Меню и футеры связаны с новыми страницами. Этапы услуг реализованы через нативные details/summary; в макете показан текст только первого этапа. Остальные этапы содержат сообщение об уточнении состава на консультации. Форма консультации не отправляет данные без API.
